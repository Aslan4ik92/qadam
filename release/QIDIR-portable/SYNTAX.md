# Синтаксис запросов QIDIR

QIDIR старается понять запрос так, как его набрал бы обычный человек: просто слова через пробел. Всё остальное — необязательные уточнения.

## Режимы

| Режим | Что находит | Пример |
|---|---|---|
| **Умный** (по умолчанию) | Все словоформы запроса. Русский и английский — стеммер Snowball, казахский — стеммер суффиксов QIDIR. Точные формы ранжируются выше. | `яблоко` → *яблоки, яблоком*; `кітап` → *кітаптар, кітаптарымызда*; `run` → *running* |
| **Точный** | Только введённые словоформы (регистр и `ё/е` не важны, казахские буквы всё так же сворачиваются). | `яблоко` → только *яблоко* |

В обоих режимах:

- регистр не важен: `Договор` = `договор`;
- `ё` = `е`: `ёлка` = `елка`;
- казахские буквы сворачиваются к русским: `қ→к ә→а ғ→г ң→н ө→о ұ→у ү→у һ→х і→и`, поэтому `Казакстан` находит «Қазақстан», а `білім` можно набрать как `билим`;
- латиница теряет диакритику: `resume` найдёт «résumé»;
- слова разделяются любыми небуквенно-цифровыми символами: `Отчет_2023_final.docx` содержит слова *отчет*, *2023*, *final*, *docx*.

## Операторы

| Запрос | Значение |
|---|---|
| `договор аренды` | оба слова где угодно в файле (AND) |
| `"договор аренды"` | слова подряд именно в этом порядке (в умном режиме — в любых формах) |
| `«договор аренды»` | то же самое, «ёлочки» тоже понимаются |
| `договор OR контракт` | любое из слов. Также `ИЛИ`, `НЕМЕСЕ`, `\|` |
| `договор -расторжение` | без второго слова. Также `NOT`, `НЕ`, `ЕМЕС`, `!слово` |
| `догов*` | слова, начинающиеся с «догов» |
| `д?говор`, `дог*р` | маска: `?` — один символ, `*` — любое количество |
| `договр~` | нечёткий поиск, одна опечатка. `слово~2` — две опечатки |
| `name:отчет` | слово в имени файла. Также `имя:`, `файл:`, `атау:` |
| `ext:pdf` | расширение файла. Также `тип:` |
| `path:2023` | слово в пути к папке. Также `путь:`, `папка:`, `жол:` |
| `content:слово` | только в тексте файла, не в имени. Также `текст:`, `мәтін:` |

Операторы можно комбинировать: `name:протокол "совещания" ext:docx -проект OR черновик`.

Обычные слова ищутся одновременно в тексте файла и в его имени; совпадение в имени файла весит больше.

## Что ищется по имени, а что по содержимому

- Форматы, которые QIDIR умеет читать, индексируются целиком — текст, колонтитулы, примечания, все листы таблиц, все слайды.
- Файлы неизвестных форматов (`.exe`, `.jpg`, `.zip`, …), слишком большие файлы и файлы, которые не удалось прочитать, индексируются **по имени и пути**. Фильтр «Только файлы с текстом» скрывает их.

## Сортировка и фильтры

Фильтры в боковой панели (папки, тип файла, расширение, дата изменения, размер) объединяются с текстом запроса по AND. При пустом запросе QIDIR показывает все файлы, подходящие под фильтры, отсортированные по дате изменения — удобно, чтобы посмотреть недавние документы.

Сортировка: по релевантности (BM25 + бонус за совпадение в имени файла), по дате, размеру, имени.

## Как QIDIR читает запрос

Строка под полем поиска показывает интерпретацию запроса, например `(договор OR контракт) AND "аренды помещения" AND -расторжение`. Команда `qidir analyze "текст"` показывает, на какие термы разбивается любой текст.

## English summary

Words are ANDed. `"phrase"`, `a OR b`, `-excluded`, `prefix*`, `wild?card`, `fuzzy~` / `fuzzy~2`, `name:`, `ext:`, `path:`, `content:`. Smart mode is morphology-aware for Russian, Kazakh and English; Exact mode matches exact word forms. Case, `ё/е`, Kazakh-specific letters and Latin diacritics are folded in both modes.
