# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-08

Первый выпуск.

### Добавлено
- Режим браузера: встроенный локальный сервер (`qidir-server`) отдаёт интерфейс любому браузеру, если среды WebView2 нет (`QIDIR.exe --browser`, `qidir serve`).
- Множественный выбор типов файлов, расширений и папок в фильтрах (дизъюнктивные фасеты).
- Диагностика запуска: проверка WebView2, окно с ошибкой при сбое, `--console`, устойчивое логирование.
- Ядро поиска `qidir-core` на tantivy: инкрементальное параллельное индексирование, манифест отпечатков (redb), наблюдение за папками, отмена.
- Многоязычный анализатор RU/KZ/EN: стемминг Snowball для русского и английского, собственный стеммер казахских суффиксов, свёртка `ё/е`, казахских букв и латинской диакритики, индексирование стема и точной формы на одной позиции.
- Экстракторы: текст в любых кодировках (cp1251, KOI8, CP866, UTF-16 без BOM), DOCX/PPTX, ODT/ODP, XLSX/XLSB/XLS/ODS, DOC (Word 6–2003), PDF, RTF, HTML, EPUB, FB2/XML, исходный код.
- Язык запросов: фразы, OR/NOT (в т. ч. русские и казахские операторы), исключения, префиксы, маски, нечёткий поиск, поля `name:`, `ext:`, `path:`, `content:`; фильтры, фасеты, сортировки, сниппеты и подсветка предпросмотра.
- Приложение для Windows на Tauri 2 + Svelte 5: интерфейс в стиле Windows 11, светлая/тёмная темы, локализация на русский, казахский и английский, виртуализированная выдача, панель предпросмотра с навигацией по совпадениям, диалог настроек, установщики NSIS и MSI.
- Консольная утилита `qidir` (index, search, preview, extract, analyze, stats).
- CI: тесты на Linux и Windows, сборка установщиков, публикация релизов.
